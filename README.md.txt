# ChaCha’s Popcorn Website

Django-ready frontend build for the ChaCha’s Popcorn e-commerce website.

This V1 includes the full customer-facing commerce flow, reusable templates, static assets, product detail routing, frontend cart/checkout shells, account pages, support/legal pages, a 20% off email popup, a cookie banner, and a reusable popcorn parallax background partial.

---

## Local Setup

From the project folder:

```bash
cd ~/Desktop/chachas-site
source .venv/bin/activate
pip install -r requirements.txt
python3 manage.py runserver 8001
